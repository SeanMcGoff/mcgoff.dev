About this Site

This website is deliberately plain. It is designed with accessibility over everything, hence why there is no JavaScript in use at all. If something could be made better in this regard, please let me know!

Notice on Irish-language content

Please note that I'm not a native Irish speaker, and that the Irish-language articles on this site double as practice for me. I'll do my best to correct mistakes when I see them, but a few will inevitably slip through. If you are a learner yourself, be warned!
