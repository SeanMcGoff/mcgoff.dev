About this Site

This website is very deliberately plain. You can use all the features of this site without JavaScript enabled, and it is optimized for accessibility.

Please note that I'm a learner in Irish, and that the Irish-language articles on this site double as practice for me. I'll do my best to correct every mistake, but I'm sure that I'll make a few. If you are a learner yourself, be warned!
